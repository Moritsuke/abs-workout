# 腹筋トレーニングタイマー（音声選択機能追加版を基にした修正版）

## 公開方法（GitHub Pages）
1. このZIPを解凍します。
2. `index.html`、`manifest.webmanifest`、`sw.js`、`icon.svg`、`README.md` をGitHubリポジトリの直下にアップロードします。
3. GitHubの **Settings → Pages** で、公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/(root)` にして保存します。
4. 表示された公開URLをChromeで開きます。

## 主な機能
- 作成済みメニューの選択・編集・保存・名前変更・削除
- 新規メニューの追加、種目の追加・削除
- メニューの保護と保護解除。保護中は編集・名前変更・削除を禁止
- 回数・秒数・セット数・セット間休憩の設定
- 回数カウント音声、セット終了案内、完了時の「お疲れ様でした」
- 標準音声2種類（女性・男性各1種類）（女性・やさしい／女性・元気／男性・落ち着いた／男性・力強い）
- 標準音声は端末のブラウザ音声合成を利用します。声質は端末により異なります。
- 音声選択は女性・男性各1種類とし、「自分の声に近い声（録音した声色を基にAIが音声生成）」を選ぶとCoeFont公式サイトを新しいタブで開きます。
- CoeFontでダウンロードしたMP3/WAV等の音声を音声設定から場面別に取り込み、IndexedDBに保存できます。同じブラウザで次回起動時も利用できます。
- カウント音声は数字ごと（1〜99）、セット終了音声はセット番号ごと（1〜30）または共通、終了時の「お疲れ様でした」を個別登録できます。未登録の音声は端末の音声合成にフォールバックします。
- 音声は同じ端末・同じブラウザ内に保存されます。ブラウザデータの削除や別端末への移行で消える場合があります。
- 録音した声色を基にAI音声を作成したい場合のみCoeFontを利用します。アプリはCoeFont APIに接続しません。
- メニュー設定は利用端末のブラウザに保存されます。


## 自分の声を録音する
音声設定で「録音した声（CoeFont用の録音画面へ）」を選ぶと、録音画面が開きます。「録音開始」を押すと案内音声が流れ、その後に表示された文章を読み上げて録音します。停止後に試聴し、録音ファイルをダウンロードしてCoeFont側で利用できるか確認してください。録音はHTTPSのGitHub Pagesとマイク許可が必要です。録音ファイルを作っただけでは声のAI化は行われません。
