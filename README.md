# 腹筋トレーニングタイマー PWA

## 公開方法（GitHub Pages）
1. GitHubで新しいリポジトリ（例: `abs-workout-timer`）を作成します。
2. ZIPを解凍し、中の4ファイル（`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`）をリポジトリのルートにアップロードします。
3. リポジトリの Settings → Pages を開きます。
4. Build and deployment を「Deploy from a branch」にし、Branch を `main`、フォルダーを `/(root)` にして Save。
5. GitHubに表示されたHTTPSの公開URLをAndroidのChromeで開きます。

## Androidホーム画面への追加
1. 公開URLをChromeで開く。
2. 右上の ⋮ メニューを開く。
3. 「アプリをインストール」または「ホーム画面に追加」を選択。
4. 画面の案内に従って追加し、ホーム画面のアイコンから起動。

## 機能
- クランチ15回×3、レッグレイズ15回×3、ツイストクランチ左右各15回×3、プランク30秒×3
- 30秒休憩、音声案内、回数カウント、自動進行、一時停止・リセット
- Service Workerによるキャッシュ対応

## 音声
初回に「音声テスト」を押し、メディア音量と日本語読み上げ設定を確認してください。省電力設定や画面消灯により、バックグラウンドのタイマー・音声が制限される場合があります。最初は画面を点灯したまま使用してください。

## 注意
これはPWAのソース一式です。インターネット上への公開やGitHubへのアップロード自体はこちらから実行できません。公開URLができたらChromeで開いてインストールしてください。
